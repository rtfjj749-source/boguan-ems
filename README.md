# 臺中市消防局 鳳凰救護大隊 博館分隊 - 救護義消智慧協勤與榮譽履歷系統 (EMS Volunteer Copilot)

🚑 專為台中市博館分隊救護義消同仁打造的智慧協勤與榮譽履歷管理系統。

## 🌟 系統亮點功能

1. **⚡ 一鍵協勤簽到與時數累積**：快速登記簽到，自動累計協勤時數與累積點數。
2. **📈 救護案件登錄與自動統計**：整合急症、創傷、OHCA 與拒絕送醫等出勤紀錄，支援 1 鍵匯出標準 Excel 報表。
3. **🏆 榮譽成就與徽章系統**：提供救護之星、急救先鋒等階級評定與榮譽徽章，激勵義消同仁出勤熱忱。
4. **☁️ Supabase 雲端多裝置同步**：支援本機展示模式與 Supabase 雲端資料庫雙軌運行，分隊同仁跨手機、平板、電腦資料即時同步。
5. **📱 響應式雙視角切換**：支援手機端行動視角與電腦端寬螢幕後台視角。

## 🚀 部署說明 (GitHub Pages)

本系統為純靜態架構（HTML5 / Vanilla CSS / Modern JavaScript），可直接透過 GitHub Pages 免費託管：

1. 前往 GitHub Repository 的 **Settings** -> **Pages**。
2. 在 **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
3. 約 1~2 分鐘後即可取得公開網址：`https://<你的GitHub帳號>.github.io/<儲存庫名稱>/`。
